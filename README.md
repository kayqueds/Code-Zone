## 📝 Visão Geral
**Code-Zone** é um jogo de plataforma 2D cooperativo. Dois jogadores devem atuar em sintonia para superar fases desafiadoras, evitar armadilhas fatais e derrotar um chefe final épico que exige coordenação absoluta.

## 🚀 Funcionalidades
* **Multiplayer Local:** Experiência para dois jogadores com controles independentes.
* **Mecânicas de Sobrevivência:** Sistema completo de vida, respawn e invulnerabilidade temporária.
* **Movimentação:** Pulo duplo (Double Jump) fluido.
* **Progressão:** Sistema de portal cooperativo para transição entre fases.
* **Perigos:** Obstáculos letais (Lava e Espinhos) com colisão otimizada.
* **Boss Final:** Combate contra chefe com mecânicas únicas focadas em cooperação.

---

## 🛠️ Estrutura Técnica
* **Engine:** Godot 4.x
* **Gerenciamento de Cenários:** `TileMapLayer` (Terreno, Decoração e Riscos).
* **Lógica:** GDScript estruturado em sinais (Signals) e máquinas de estado.
* **Assincronia:** Uso de `await` para controle preciso de animações.
* **Versionamento:** Git + GitHub com fluxo de trabalho organizado.

---

## 💡 Desafios Superados
* **Otimização Física:** Sistema de colisão refinado utilizando grupos do Godot.
* **Multiplayer:** Sincronização lógica entre jogadores para ativação de portais.
* **Código Assíncrono:** Controle robusto de animações e estados via sinais.
